#  ShrimPosture: An interactive desk posture companion inspired by a shrimp sitting at a computer
ShrimPosture is an interactive desk companion inspired by the meme of a shrimp hunched over a computer!
We wanted to turn this funny idea into something that encourages people to become more aware of their sitting habits while studying, gaming, or working.
The project features a shrimp sitting in a miniature shell-shaped chair. When the user moves too close to their computer for a certain amount of time, the shrimp will gradually curl forward as a gentle reminder to move back.
Rather than interrupting the user with constant notifications, we want ShrimPosture to communicate through physical movement.

## Why we made it?

Spending long hours in front of a computer can make it easy to forget about our sitting habits. So we wanted to explore a more playful way to encourage awareness of these habits, combining electronics, programming, and 3D design into one interactive character.

ShrimPosture is our attempt to make a functional desk companion that is both useful and fun!:D

## How It Works?

The idea for the interaction has four main simple steps
**1. Calibration**
The user presses a button to record a comfortable reference distance from the sensor.

**2. Distance Detection**

A distance sensor monitors how close the user is relative to the calibrated reference.

**3. Shrimp Movement**

If the user remains too close for several seconds, a servo motor gradually moves the shrimp forward and a miniplayer will tell you to move back!

**4. Returning to Position**

When the user moves back to the calibrated distance, the shrimp returns to its initial position.

Our first version focuses on detecting changes in distance rather than directly measuring body posture.
